📖 新手使用说明（第一次用，先看这里）

这个程序是干什么的？

给你指定的一批图片做目标识别：先用 YOLO 模型在每张图里找出所有目标（画框），再用 CLIP 判断每个框里是哪个类别。全部在你电脑本地运行，图片不会上传到任何地方。

使用前，你需要准备好几样东西

东西说明
① YOLO 模型一个训练好的 .pt 文件。它是"找框"的角色。
② 要识别的图片一个文件夹，里面放图片（png / jpg / bmp / webp）。也可以直接拖进本页的虚线框。
③ 参考集文件夹教 CLIP 认类别的"教材"：每个子文件夹 = 一个类，文件夹名就是类名（建议用英文），每个子文件夹里放该类例图 10~20 张。
④ 排除参考集（可选）放"不要的东西"（杂项、容易被误认的角色等）。匹配上这些的框会被自动排除，不进最终结果。

操作步骤（就四步）

  1. 填路径：把上面四个路径填进输入框（图片文件夹和输出文件夹可以留空，会用程序自带的）。
  2. 开始识别：点「▶ 开始识别」。第一次运行要加载模型，可能要等 1 分钟左右。
  3. 核对结果：结果按图片分组显示，每张图上画了带编号的框，下方表格对应每个框：类别判错了用下拉菜单直接改；多余的框点「删除」；置信度低的（黄色数字）重点看。
  4. 保存：点「💾 保存修正结果」，最终标注图 + result_table.csv（Excel 能开的明细表）会写进输出文件夹。

两个省事按钮

  • 🕘 填入上次输入：把你上一次成功识别时填的路径一键填回来
  • 💾 保存为默认：把现在填的路径存为默认，下次打开页面自动填好

常见问题

  • 参考集怎么建？ 建一个文件夹，里面按类别建子文件夹（类名用英文，会直接画在框上），每个子文件夹放该类例图。图带背景没关系，角色占画面主体、清楚即可。
  • 类名为什么建议英文？ 类名要画在图片的框上，中文画不出来（会显示成乱码）。
  • 识别结果里出现"排除"？ 那是被排除集拦下来的框，保存时自动剔除；如果它其实是对的，在下拉菜单把它改回真类就行。
  • 换了识别目标怎么办？ 不用动程序：换一个参考集文件夹（按新类别建子文件夹放例图），运行时把路径给它就行。换 YOLO 模型同理，换个 .pt 路径即可。
  • 窗口/页面怎么关？ 关掉黑色命令行窗口 = 关闭程序。
