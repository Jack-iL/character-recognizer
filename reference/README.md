# 参考集 (Reference Set) 使用说明

本目录是**识别参考集**的骨架：**每个子文件夹 = 一个类别**，子文件夹名就是类别名。

```
reference/
├── class1/     ← 类 "class1" 的例图放这里（10~20 张）
├── class2/     ← 类 "class2" 的例图
└── class3/     ← 类 "class3" 的例图
```

## 怎么用

1. 把 `class1`、`class2`、`class3` 重命名成你自己的类别名（**用英文**，会直接画在识别结果的框上）
2. 每个文件夹里放该类例图 **10~20 张**：角色/物体占画面主体、清晰即可，带背景没关系
3. 想识别更多类别？再建新的子文件夹即可，程序不需要改代码
4. 运行时把这个 `reference` 文件夹的路径填进程序的"参考集文件夹"一栏

## 排除集（可选）

仓库根目录还有一个 `exclude/` 文件夹，用于"**不要的东西**"：

- 直接把**图片**放进去（不需要建子文件夹）
- 识别时如果某个框匹配上这些图片，会被自动标记为"排除"，不进最终结果
- 典型用法：容易被误认的其它角色、杂物、画面文字等

程序运行时把它填进"排除参考集文件夹"一栏；留空表示不排除任何东西。

## 注意

- 例图的题材（角色形象等）**可能受版权保护**，请自行准备并遵守相关法律法规。
  本仓库不包含任何参考图片，只提供空目录结构。
- 类别名建议用英文：类名会绘制在图片的框上，中文无法渲染。
- **图片默认被 `.gitignore` 忽略**（防止误把个人素材/受版权保护的图传上公开仓库）。
  如果你确实要把某张图纳入版本管理，请显式强制添加：`git add -f 图片路径`。
